Add a calendar

Every SportsCal setup starts here: paste one iCal URL from your kid's sports app, and the events show up on the family Dashboard automatically. About a minute, no tech skills needed.

Works with TeamSnap, GameChanger, PlayMetrics, SportsYou, SportsEngine, BYGA, and about a dozen more.

Where to find the URL in your sports app
TS
TeamSnap
Team page → Schedule tab → three-dot menu → Subscribe to Calendar → Copy the webcal URL.
GC
GameChanger
Team page → Settings gear → Calendar subscription → Copy link. Works on the web app, not the mobile one.
PM
PlayMetrics
Family app → Calendar → Share icon → Subscribe (iCal) → Copy the link.
SY
SportsYou
Team → Calendar → Export icon → Subscribe URL → Copy.
SE
SportsEngine
Team page → Schedule → Subscribe → Copy the .ics link.
BY
BYGA
Team → Export calendar → Copy the URL. If you only see an email option, tap it and copy the link from the email.
📅
Google Calendar
Calendar settings → Integrate calendar → Copy the Secret address in iCal format. Keep it secret — anyone with the link can see the events.
💬
Not on this list?
Most sports apps let you export a calendar somewhere in Team settings. Or use Chat with Coach — Coach walks you through the exact taps for your app.
